# 大力神：不用参考图也能下达的指令

以下以你提供的 12.01 秒视频中可见的造型和视觉效果为目标，不是把当前 V2 的简化结构当作参考原作。纯文字能描述设计方向，不能保证逐个零件复刻；生成一张三维风格图片，也不等于生成可编辑三维模型。

建议先用第一段出图，再根据结果追加第二节的局部约束。不要一开始同时要求图片、建模、视频和变形动画。

## 一、可直接使用的出图 Prompt

生成一张大力神 Devastator 工程机械合体机器人的高精度三维灰模雕像渲染图。主体是完整站立的人形重型机甲，不是四足机械兽。整体是宽肩、厚胸、收窄的机械腰部、长而有力量感的双腿，小头嵌在高耸的工程机械肩甲之间。各部分由挖掘机、推土机、装载机、混凝土搅拌车、起重机等工程车辆的车壳、履带、轮组和液压机构重组而成，保留车辆辨识度，但不是把几辆完整小车堆在人体外面。

胸口是向两侧展开的厚重 V 形折板桥架，具有分层装甲、内凹机械骨架、散热格栅和斜向支撑。肩部不对称，斜置履带、配重舱和推土铲融入肩甲轮廓。头盔棱角鲜明，有后掠护甲、窄眼缝、颧骨护板和独立下颌，表情冷峻。机器人自身右臂弯曲，分节机械拳头抬到肩旁；自身左臂向侧方伸展，握持长形四管重炮，炮口略向下，形成舒展的斜向轮廓。手指、拇指和腕部关节清楚可辨。

机器人自身右腿融合装载机底盘、轮组和弯曲铲斗脚；自身左腿融合带锥形收口的搅拌罐、轮组及卡车驾驶室脚，驾驶室保留挡风玻璃、侧门、踏板和保险杠。背部有多级伸缩吊臂、滑轮、钢索和悬垂吊钩，周围布置发动机舱、排气管和散热器。使用大块承重结构、中等尺度的车辆外壳和小尺度的液压管线三层细节；密集但有秩序，零件连接可信，不用均匀重复的螺丝代替结构设计。

站姿具有重量和张力：双腿分开、膝盖略弯、一脚前踏并踩在较高的破损台面上，骨盆与胸部轻微反向扭转，两脚真实接触支撑面。脚下是形状不规则的破损工业混凝土残骸，有断裂边缘、碎石、少量管道和外露钢筋，不要整齐的玩具展示圆盘。

保持浅灰色未涂装数字雕塑的 clay render 效果，所有部件属于同一灰阶体系。装甲为哑光浅灰，轮胎和凹槽略深，机加工边缘只带克制的柔和高光，不要镜面铬金属。清楚的微小倒角、装甲厚度、接缝和自然环境遮蔽增强立体感。采用大面积柔光与充分补光，明亮但不过曝，背面和暗部的机械细节仍可辨认。

使用均匀的偏冷中灰纯色背景，背景不显示地平线和摄影棚地面；主体仍由自己的残骸底座支撑，不悬空。略低机位、正面偏侧约 35 至 45 度的三分之四透视，建议使用等效 55mm 镜头的自然透视观感。完整保留头部、炮口、双脚和底座，主体占画面高度约 85%，周围留出安全边距，全身清晰，不要景深模糊。无文字、无水印、无界面。

## 二、局部修正和效果替换

每次选择最重要的一至两条追加，不要把互相冲突的要求同时加入：

- 胸部太薄：胸甲不是平面盾牌，增加折板侧壁、前后层次、内部横梁和深凹散热结构，保留中央机械脊柱。
- 像方块玩具：让前臂和小腿截面逐段变化；外壳采用收分、折面和错层的车辆钣金，不用等尺寸长方体贯穿整个肢体。
- 手部不清楚：四根分节手指加独立拇指，指节有转轴与护甲；握拳时拇指压在弯曲手指侧前方，握炮时手指包住握把。
- 工程车辨识度不足：保留履带板、支重轮、搅拌罐锥形尾部、驾驶室门窗和弯曲铲斗，让这些大特征先于螺丝细节可读。
- 姿态太僵：扩大左右脚的前后错位，弯膝、转胯、胸部反向扭转，武器向侧方舒展；保持支撑关系，不让脚底离地。
- 灰模太黑：提高环境补光，装甲改为哑光浅灰，凹槽保留阴影但不糊成黑块；背景保持冷中灰，而不是黑色。
- 改成当前 V2 的棚拍效果：仅替换材质与环境段为“中灰喷砂装甲、略亮的机加工边缘、深灰轮胎和凹槽；深中性灰连续弧形摄影棚，地面可见并带柔和接触阴影，左前上方主光、较弱补光和后侧轮廓光”。不要与“纯色背景、不显示棚面”同时使用。
- 想要完全原创角色：将“大力神 Devastator”替换为“原创工程机械合体机器人”，其余结构描述保留。

负面约束可按需要追加：不要多余手脚、对称复制的双腿、单块方盒拳头、薄片胸甲、整辆小车堆叠、脚底悬浮、明显穿插、背面缺失、炮口出画、镜面铬、绿色紫色涂装、发光灯带、浓烟、背景建筑或过度模糊。

## 三、短版 Prompt

大力神 Devastator 工程机械合体机器人，全身高精度三维灰模雕像。宽肩厚胸、收腰长腿、小型棱角头盔；厚重 V 形分层胸甲，履带和推土铲融合的非对称肩甲。自身右手握拳抬到肩旁，左手向侧方握持略朝下的四管长炮。右腿为装载机底盘和铲斗脚，左腿为锥形搅拌罐和卡车驾驶室脚。背部完整伸缩吊臂、钢索、吊钩和动力舱。车辆外壳、轴承、液压缸、管线形成有秩序的多尺度机械细节。弯膝宽站姿，一脚前踏抬高，胸胯轻微反向扭转，双脚接触不规则工业混凝土残骸底座。哑光浅灰 clay render，克制高光、细倒角和清楚接触阴影。冷中灰纯色背景，无地平线，大面积柔光、充分补光。略低机位、55mm 自然透视、正面偏侧 40 度，完整模型和底座入镜、全身清晰。无彩色涂装、悬浮、穿模、文字或水印。

## 四、需要真实 Blender 模型时追加

交付可编辑三维资产，不仅是看起来像三维的图片。按头部、胸腹、左右肩、左右臂、炮、骨盆、左右车辆腿、背部吊臂和底座组织对象。采用可编辑的分层硬表面网格、适量倒角、独立材质和明确父子关系；用承重梁、连接面和关节表达结构关系，不以明显穿插强行连接。保留原始对象，另导出应用修改器的静态 GLB。检查法线、材质、外部依赖、双脚接触、关键非关节间隙和背面完整性。输出 .blend、GLB、正面、三分之四、背面及头胸特写。

先验收整体轮廓与姿态，再验收车辆大部件，最后增加机械细节和灯光。此任务不包含真实变形机构；不要仅凭合体造型声称它能拆分变形成六辆工程车。

## 五、需要 12 秒展示视频时追加

为同一个已完成的真实三维模型制作 12 秒、1920×1080、24fps 的完整 360 度展示。机器人和底座保持同一刚性姿态，相机匀速绕模型一整圈，从三分之四视角出发，经过两个侧面和背面后回到起始方向。固定焦距、高度、环绕半径和灯光，不推拉、不跳切、不变焦、不变形、不增减零件。全程完整保留头部、炮口、双脚和底座。输出 288 帧，循环末尾不额外重复第一帧，H.264 MP4，无音轨、字幕、水印。逐帧检查裁切、空白、冻结和首尾衔接。

默认沿用第一节的浅灰雕塑、冷灰纯色背景。要匹配本次交付视频，则使用第二节的深灰摄影棚替换段。视频中能观察到的是相对环绕效果，单凭素材不能确定原作者究竟旋转了相机还是模型；这里指定相机环绕是为了让执行方式明确。

## 六、学习如何写出有效指令

可复用顺序：**交付类型 → 主体和比例 → 大部件归属 → 姿态与接触 → 细节层次 → 材质 → 光线和背景 → 镜头构图 → 具体禁项。**

| 想表达的效果 | 更可执行的描述 |
| --- | --- |
| 很有力量 | 宽肩厚胸、收腰、膝盖略弯、两脚错位、重心落在双脚支撑区域 |
| 很像工程机械 | 指定哪条腿有搅拌罐、哪只脚有驾驶室、哪些肩甲由履带和推土铲组成 |
| 细节很多 | 承重骨架、车辆外壳、管线铰链三个尺度，有明确连接和疏密变化 |
| 有三维质感 | 装甲厚度、细小倒角、粗糙度差异、柔和高光和接触阴影 |
| 看起来像参考视频 | 浅灰哑光灰模、冷中灰平背景、明亮柔光、全身无景深模糊 |
| 多视角保持一致 | 使用同一个真实三维资产环绕渲染，不分别生成各视角后假定它们一致 |

55mm、35 至 45 度、85% 占比是便于执行的建议值，不是从参考视频精确测量的原始相机参数。不要把“8K、电影级、超精细”当作上述结构描述的替代词。

当前 V2 是可编辑的近似版本：姿态较直立，头手和外壳较简化，背部吊臂更贴近竖直，底座也更规则。提示词描述的是参考方向，不能用来证明 V2 已达到参考作品的精细程度。
